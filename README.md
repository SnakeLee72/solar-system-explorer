# 3D 星系探索器

用 Three.js 做的互動式太陽系探索器：開飛船在太陽系裡巡航，點行星看真實天文資料。

## 玩法

直接用瀏覽器開啟 `index.html`，或到 GitHub Pages 上玩。

- **W / S**：向前／向後推進（煞車、後退）
- **A / D**：向左／向右轉
- **Q / E**：向左／向右平移
- **Space / Z**：上升／下降
- **C**：星座總開關（或按右上「✦ 星座」）；**L**：星座清單（或按「☰」），可單獨顯示／隱藏、「定位」轉向並點亮
- **Shift**：加速推進（Boost）
- **滑鼠拖曳**：轉向、旋轉視角
- **點行星或按 0–9**：飛過去看資料（0 太陽、1 水星、2 金星、3 地球、4 火星、5 木星、6 土星、7 天王星、8 海王星、9 月球）
- **P**：暫停時間，**T**：切換 1x / 10x / 100x，**M**：自由總覽，**R**：返回飛船，**H**：操作說明

## 內容

- 太陽＋八大行星，依真實公轉週期運行，行星位置以當日真實位置起算
- 所有紋理皆程序化生成（木星大紅斑、土星環卡西尼環縫、地球雲層、月球）
- 650 顆小行星帶、軌道線、銀河星空
- 23 個星座＋1 個星群（夏季大三角，虛線），亮星依真實 J2000 赤經／赤緯換算到黃道座標，畫在遙遠天球上；黃道星座會落在行星軌道面附近
  - 春季：北斗七星（大熊座）、獅子、室女、牧夫
  - 夏季：天蠍、天鵝、人馬（茶壺）、天鷹、天琴、夏季大三角（星群）
  - 秋季：仙后、飛馬、仙女、南魚、雙魚、寶瓶
  - 冬季：獵戶、雙子、金牛、大犬、小犬、御夫
  - 全年可見：小熊、天龍
- 星座清單依季節分組、可收合（預設展開當季），每組可整組開關
- 行星資料皆為真實數值：直徑、與太陽距離（AU／公里）、公轉週期、自轉週期、冷知識

手機也支援觸控操作（拖曳轉向、按鈕推進）。

## 技術

單一 HTML 檔，Three.js 0.160.0（cdnjs CDN），其餘零外部依賴。
